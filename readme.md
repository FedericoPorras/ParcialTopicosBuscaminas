## Minesweeper – Parcial Tópicos

This project was developed as a practical exam for "Topicos de Programación" at the university (UNLaM). 
It has some things to fix, the last version uploaded here **it's not finished**, but could help you to pass this subject (You can get ideas from here).

It's recommended to use the entire graphics library instead of just few functions (for greater reliability).
This library was designed to be functional in various projects and to simplify the use of SDL.
